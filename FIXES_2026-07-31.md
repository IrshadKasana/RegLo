## C. 24 h-walltime robustness (train **and** eval)

* Meta-training already checkpoints `<model>_resume.pt` after every
  epoch-block with the adaptive 1.25×-last-block deadline. **Proven by
  execution here**: WALLTIME_EXIT → resume block 1/2 (loss improved) →
  WALLTIME_EXIT → resume block 2/2 → natural completion, resume file
  auto-removed, traininfo written (`stop_reason`, `meta_train_flops`).
* Evaluation dumps a per-instance partial JSON and resumes at the first
  unfinished instance (per-instance seeds are `seed+i`, so resumed instances
  are bit-comparable). **Proven by execution** with the SGD PACS run:
  WALLTIME_EXIT after instance 0 → resubmit → resumed at instance 1 →
  final JSON written, partial removed.
* **New chain guard** (`optimizee_train.py`): if the final timestamped JSON
  for this exact run already exists and no partial does, a resubmitted job
  prints `[resume] final result already present` and exits in seconds instead
  of re-running everything and writing a duplicate. `--set overwrite=True`
  forces a redo.
* **`submit_chain.sh` upgraded** for multi-day runs:
  * `bash submit_chain.sh chain N job.pbs …` — submit N copies of the same
    script, each `-W depend=afterany` on the previous ⇒ day-2/3/… resume is
    automatic. Pick N = expected days; surplus links exit in seconds thanks
    to the guard.
  * `bash submit_chain.sh sweep [N]` — 108 exp1 cells in parallel, each
    optionally self-chained N days.
  * `bash submit_chain.sh phases N` — train→eval→bench→report with train and
    eval self-chained N days.
* Plot loader now **skips partial dumps** (`ev_pt_*`; the old `partial_`
  prefix check never matched the real naming), so half-finished runs can no
  longer leak into reports.

## E. Design flags (decisions for the paper, not silently changed)

1. **GSAM ≡ SAM in penalty mode, gradient-wise.** `L_reg = L_adv −
   L_task_val` subtracts a *detached float*, so ∇φ is identical to SAM's
   `L_adv`; with the shared ascent radius the two arms differ only through
   their swept λ values. The paper's Eq. 17 α-weighted orthogonal ascent is
   not implemented (the PDF itself lists α as unspecified). Either implement
   the decomposition before retraining, or disclose the simplification.
2. Generalization-gap "train" side is measured with the augmented train
   transform (consistent across all methods; note it in the caption).
3. `fit_w_normal_optimizer` performs one redundant fwd+bwd before GAM/GSAM's
   `set_closure` re-computes gradients — wasted compute only, left as-is.
