# Run Scripts

This folder contains shell scripts for launching the main DMO experiments.

Included scripts:
- `run_paper_experiments.sh`: run the paper experiment matrix.
- `slurm_train.sh`: example SLURM submission for training.
- `slurm_eval.sh`: example SLURM submission for evaluation.

These scripts are copies of the active experiment entrypoints and are intended to centralize runner helpers under `src/run`.
