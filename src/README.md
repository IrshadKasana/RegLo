# Source Directory

This repository's active source code lives under `src/learning_regularizers/dmo`.

- `src/learning_regularizers/dmo`: active DMO implementation for meta-training and optimizee evaluation.
- `src/run`: shell scripts for launching experiments.

Use `src/learning_regularizers/dmo/train.py` and `src/learning_regularizers/dmo/optimizee_train.py` for the main DMO workflows.
